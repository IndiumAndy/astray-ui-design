2026 年 11 月 18 日。基线为阶段 1 提交 `4a76f6d` 及工作区中的阶段 2 双端运行实现。复测使用 macOS 26.3、Xcode 26.6 和 iPhone 17 Pro 模拟器（iOS 26.5）和 Ego Lite 浏览器。[布局验收样例](布局验收样例.uidesign)

## 用例

| 用例 | 实际结果 |
| --- | --- |
| 参考布局和底图 | 登录参考指引可出现在零图层画板上。自动检查距边缘 3 pt 的控件吸附到参考框。实窗锁定底图后，将登录标题从 Y=88 拖到 Y=208，底图坐标保持 (0, 0)，结果已存盘。运行数据只包含作品图层，导出也使用该数据。 |
| 自由摆放后设为排列 | 自动检查三项输入框由自由摆放转为纵排。首项加入提示文字，后两项下移，保留 12 pt 间距。复测还覆盖横排、窄宽堆叠和组合子项改序。 |
| 宽高独立 | 自动检查将填满宽度的输入框调到 240 pt，宽度切为固定，高度继续随内容。改回填满后，在 820 pt 平板画板解析宽度为 772 pt。坐标与尺寸随文档存盘重开。 |
| 设备和覆盖 | 自动检查六种比例、横竖交换、各设备布局覆盖、恢复通用布局与共享文案。Swift 和 Web 的布局计算在 390、430、820、1080、1440 五个宽度对照，位置与尺寸一致。 |
| 长设置页 | Mac 实窗确认默认 390 × 844 画板与「展开整页」后的首屏边界。Mac 实窗用鼠标将「同步联系人」从第 18 行拖到第 3 行，确认自动保存。用「Edit → Undo」恢复原顺序并确认存盘。iPhone 独立导出实际滑至最后一行，标题和两个底栏按钮的辅助功能坐标保持固定，底栏位于系统安全区内。 |
| 共享按钮样式 | 自动检查五个按钮引用同一项目样式。单独调整后高度为 `64、48、48、48、48`，点「更新样式」后五个均为 `64`。各自的标题和动作数据保留。 |

## 界面复查

- Mac 沿用蓝白工具栏、浅灰组件栏、坐标网格与同一套图标。「画板设置」放在运行入口旁。编辑范围随当前设备显示，组件文字在局部布局下仍标明应用范围。
- 登录样例提供可见字段名，并将标签与输入框关联。密文输入采用系统控件。设置页只把保存按钮设为主要按钮，顶部和底部都在滚动区外。
- 窄屏堆叠以容器宽度 420 pt 为界。Web 使用 600 和 1000 CSS px 区分三类布局。组内可拖动重排，也可通过检查器输入目标序号。恢复通用布局、更新样式和所有布局提交都使用文档撤销。

## 构建与运行

- 17 项 macOS 测试通过。包含版本 1、2 文档迁移、布局、撤销和导出。
- SwiftUI 独立导出工程在 Xcode 构建并启动。Web 独立导出用锁定依赖构建。浏览器以 390、820、1200 CSS px 分别验证手机覆盖和双列布局。20 行设置页滚动 568 px 后末行可见，两条固定栏坐标保持，末行开关可操作。联系人示例仍可打开对应记录。
- 在 Mac 内嵌模拟器中拖动设置页，确认正文滚动约 729 pt，标题和底栏保存按钮的坐标固定。

## 试用入口

打开样例后默认进入 20 行的「设置」。在「画板设置」点「展开整页」，通过画布或图层栏选中「同步联系人」，拖到第三行或在检查器输入序号 `3`。在「页面」切换到「登录」，开启「仅改手机布局」可看到密码在邮件字段前面。切到平板或桌面后可核对顺序与列宽。按 ⌘Z 撤销一次修改。
