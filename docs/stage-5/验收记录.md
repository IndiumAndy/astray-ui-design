# 阶段 5 · 个人库与项目复用

阶段 2–4 的 Git 基线为 7ac42ec。使用 macOS 26.3、Xcode 26.6。全部 25 项 Mac 测试通过，0 失败、0 跳过。其中 4 项新增覆盖下表。

| 用例 | 实际结果 |
| --- | --- |
| 项目搬迁 | 自动测试将含图片、参考底图、项目共享样式、手机布局覆盖及页面连线的 .uidesign 整体移动到另一目录。重开验证全部内容与原项目一致。未在 Finder 手动重复该测试。 |
| 组件 | Mac 实窗从空白画板插入按钮、存入个人库，再点模板行插入，在画布看到两枚按钮。从侧栏拖模板到另一个项目，看到按钮落在画板上；按 ⌘Z 后按钮消失。 |
| 组合和整页 | 支持从所选图层保存多个控件或可拆组合，也可只选择一张画板。自动测试覆盖表单组合的保存和重复插入；实窗走的是单组件和两页流程，未另外操作单页模板。 |
| 流程和外部连线 | 用「新建交互示例」勾选「通讯录」和「联系人详情」，选择「留待重连」。从另一个空白项目插入后，Mac 实窗看到两张新画板、三条联系人示例及连接详情的蓝线。测试另外确认选区外连线去除、选择一并带入时正确包含所有目标、第二条记录继续将正确电话传到副本详情。 |
| 模板更新与隔离 | 自动测试将改进版存入同一库条目，重启存储读取新版，旧项目仍保留原文案和样式。重复插入表单时两组控件 ID、表单上下文分离，业务动作名和字段键保持；插入后可整批撤销。 |

[个人库验收样例](个人库验收样例.uidesign)由阶段 4 交互样例加入一张内嵌 PNG、共享按钮样式及手机覆盖制成，可用来按表重测。图案为本项目的合成测试素材，不依赖外部图片。

## 界面检查

个人库沿用工作台灰色侧栏、蓝色选中态和现有行组件。拖放也能通过激活行完成，保存流程也可在面板中用复选框选页面。只有确有选区外连线时才显示取舍；临时验收模板已移出个人库。参考 Apple HIG 的 Sidebars、Drag and drop、Keyboards、Focus and selection、Menus 和 Sheets，以及 unslop 的侧栏密度、对齐和文案规则。
