# 阶段 7 · 本机 stdio MCP

macOS 26.3、Xcode 26.6、内嵌 iPhone 17 Pro（iOS 26.5）。原生 Xcode 的 31 项回归测试通过，0 失败，其中 2 项属本阶段。独立 stdio 客户端的测试另行运行通过。

| 核验 | 实际结果 |
| --- | --- |
| 独立客户端 | 通过 MCP 初始化、工具发现和读取当前修订。向关闭编辑器的合成设计一次提交对齐及间距修改，两项一起落盘，重读修订已变化。 |
| 原子性与冲突 | 含无效操作的批次写入 0 项；旧修订被明确拒绝并返回当前修订。打开编辑器的集成测试在两项修改后按一次撤销，还原完整原稿。权限默认关闭；启用后仅当前窗口处理该文档。 |
| 实际模拟器 | 独立 stdio 客户端从工作台正在运行的内嵌 iPhone 取回 PNG。通过 MCP 点按从通讯录打开设置，再点「保存资料」。后续截图显示姓名字段获得焦点，姓名、密码、邮箱各显示必填提示。只记录已观察到的导航和保存校验，不将其当作通知开关、中文输入或滑动的单独通过证据。 |
| 选页及保护 | 独立 stdio 客户端选出通讯录，生成清单只含这一页和 4 个宿主导航回调。第二次指定同名目录会被拒绝，不覆盖上次结果。导出与工作台共用生成器。 |
| 预览刷新 | 打开编辑器时，批次只提交一次项目快照，调用与人工编辑相同的撤销和刷新逻辑。本轮未记录一次 MCP 批次在内嵌预览实际刷新的次数。 |
