实窗首次发现「更新已有目录」收起选页面板后，目录选择器未出现。修正为独立的原生目录面板，复测确认进入差异界面，取消、保留和替换三条路径都有效。

## 复测

1. 打开样例，在「运行」选「导出选中页面」，仅勾选通讯录，将其导到新目录。在两端 README 所列入口按清单中的 openPage 事件接入宿主路由，点第二行确认宿主拿到记录。
2. 两页一起导出，并另导一份完整工程。关闭编辑器以后再构建和运行，不依赖编辑器进程。
3. 在导出目录的生成页面源文件中加一处手改，在设计里移动同一控件，用「更新已有目录」查看文件列表和对照。先取消验证所有文件不变，再分别试保留手改和采用新版本，确认宿主回调仍保留。

差异界面使用文件列表与当前/新生成源码对照，冲突进入时默认保留手改。只有选择「更新」后才写入；早期没有清单的导出可先导到新目录，再移入宿主自己的代码，不能当作可自动更新的目录。
